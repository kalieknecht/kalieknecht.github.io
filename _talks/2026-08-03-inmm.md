Radiological source search applications require rapid and accurate threat characterization. Traditionally, source search efforts have relied on manual surveys with handheld detectors or vehicle-mounted systems, which are time-intensive and expose operators to unnecessary risk. Recent advances in robotics and artificial intelligence (AI) enable autonomous systems to assume an expanded role in these missions, reducing operator burden while improving coverage and situational awareness.

This work presents a multi-agent autonomous framework for radioactive mapping using coordinated ground-based quadruped robots and unmanned aerial systems operating in complex indoor and outdoor environments as part of the Coordinated Autonomous Navigable Instruments for Nuclear Emergency Search (CANINES) project. Each platform is equipped with radiation detectors and contextual sensors, including LiDAR and visual cameras, enabling the real-time reconstruction of 3D contextual and radiation maps. Each robot is controlled by an AI agent responsible for autonomous navigation, exploration, and local decision-making using real-time radiation and contextual sensor data. 

Contextual scene understanding is derived from perception pipelines which incorporate computer vision, semantic segmentation, and language-based scene descriptions. These contextual cues are used to constrain exploration, prioritize regions of interest, and inform radiation-aware path planning. Coordination between agents enables shared situational awareness, adaptive task allocation, and large-scale scene coverage. 

The system is evaluated through a large-scale demonstration in which multiple autonomous agents collaboratively map an environment and localize radioactive sources with limited human guidance. Results demonstrate improved coverage efficiency, reduced mission time, and increased robustness relative to single-platform autonomous systems.
